# Portfolio: Varaxy Thavereak

Personal portfolio site: [varaxy.github.io/Portfolio](https://varaxy.github.io/Portfolio)

Full-stack software engineer · B.S. Computer Science, CSU Stanislaus (2026) · NSF S-STEM Scholar.

Built by hand with plain HTML, CSS, and JavaScript: no frameworks, no build step.
Quiet editorial dark design: one accent color, type-led layout, scroll-reveal animations
that respect `prefers-reduced-motion`.

## Structure

- `index.html`: single-page layout (about, projects, skills, experience, contact)
- `css/style.css`: design system and all styling
- `js/main.js`: reveals, nav state, counters, contact form

## Run locally

Open `index.html` in a browser. That's it.
